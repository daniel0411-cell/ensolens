# Historical and FAQ Release Audit

Observed: October 23, 2026 (Asia/Shanghai).
Scope: feature commit `30142d5`, documentation checkpoint `9db73c7`, and public production pages. This is an audit, not an application fix or release. Screenshot delivery claims were treated as claims to verify.

## Findings

### P1: Historical chart, dataset toggles, and CSV initialization are unreachable

- Location: `src/scripts/charts.ts:78-79`, historical initialization at lines 125-230; caller in `src/pages/historical.astro:266`.
- `initCharts()` returns if `#probability-chart` is absent. The historical page contains `#analog-chart` but no probability chart. Consequently, it never constructs the historical chart or attaches its toggle and CSV listeners.
- Production reproduction: open https://ensolens.com/historical/. The main chart area is blank. Clicking the 2015 benchmark button leaves `aria-pressed="true"` unchanged. The CSV listener is blocked by the same return; a completed CSV download was not observed or claimed.
- Impact: the primary new tool is unusable even though the page returns HTTP 200 and has no uncaught exception.
- Recommendation: make each chart's initialization independent. Verify rendered historical canvas pixels, a toggle state/data visibility change, and an actual CSV download on desktop and mobile.

### P2: The 2020 peak summary disagrees with its own weekly data

- Locations: `src/data/historical-analogs.json:995-996`, `:1260-1262`, `:1278-1280`; `src/pages/historical.astro:181-185` and `:246-247`.
- The profile and comparison matrix show -1.4 C, with November 2020 / OND 2020 timing. Metadata specifies November 18. However, the bundled weekly data reaches -1.7 C on October 28; November 18 is -1.1 C.
- Impact: the summary cannot be reconciled with the chart/CSV's stated weekly series. If the summary intends a seasonal index, it needs an explicit index, baseline, and source rather than presentation as the peak of this weekly comparison.
- Recommendation: establish the intended measurement, verify against the original NOAA series, and derive matching summaries from the validated data. This audit establishes an internal inconsistency; it does not establish which value matches upstream NOAA.

### P2: FAQ empty-state styling overrides the hidden attribute

- Locations: `src/styles/global.css:1125-1126`; `src/pages/faq.astro:141`, `:182-183`.
- `.faq-empty { display: flex; }` overrides the browser's normal `[hidden]` display behavior. There is no matching `.faq-empty[hidden]` rule. The same stylesheet explicitly handles `[hidden]` for other flex elements, but not this one.
- Production reproduction: the initial FAQ accessibility tree contains all nine questions and the message "No questions matched your search query" together. Searching for `zzzxxyynotfound` hides the questions and displays the empty panel; clearing the search restores all nine questions while the empty message remains exposed.
- Impact: users receive contradictory search feedback and an unnecessary empty panel when results exist.
- Recommendation: explicitly hide the panel when `[hidden]` is present. Check both successful and unsuccessful searches, including clearing the query.

### P2: Historical page silently omits degraded-data warnings

- Location: `src/pages/historical.astro:8` (the page destructures only `snapshot`). Compare `src/pages/index.astro:11,21` and `src/components/DataNotice.astro:6`.
- The new page uses the same live/fallback weekly snapshot as the dashboard, but drops `getData()`'s `stale` result and never renders `DataNotice` or an equivalent warning.
- Impact: after an upstream failure or overdue data, the historical page continues presenting its current-year comparison without the delayed-source warning shown elsewhere. This violates the project's explicit requirement to disclose degraded data.
- Recommendation: expose relevant weekly-source degradation and the observation date on the historical page. Verify with a simulated upstream failure. Production degradation was not induced during this audit.

## Additional Follow-Up

- `src/pages/historical.astro:10-12` and `src/scripts/charts.ts:141,226` hardcode 2026 as current. If the page should track the current year, it needs a year-rollover policy.
- `src/scripts/charts.ts:190` fixes the x-axis maximum at week 52, while the 1997 and 2020 series each contain week 53. That final point will be clipped after chart initialization is repaired.
- FAQ contains nine questions, whereas the delivery notes state eight. The direct-link control is an ordinary anchor (`faq.astro:135`), not a clipboard-copy action.
- FAQ scientific claims need primary-source review: six months / 50% for Watch, five overlapping seasons for an operational Advisory (`faq.astro:25`), a claimed physical tipping point at +/-0.5 C (`:32`), and the RONI calculation (`:39`). These are not certified as correct by this audit.
- FAQ schema is nested under a root WebSite node (`faq.astro:71-83`, `Layout.astro:10`). No rich-result validator or Search Console evidence was obtained. Do not infer Google rich-result eligibility, search inclusion, or ranking improvements from the existence of JSON-LD.
- Public NOAA/Google primary-source research was attempted through a background browser search, but browser operations repeatedly timed out. No external scientific or current rich-result policy claim is presented here as independently verified. The incomplete search was https://www.google.com/search?q=site.cpc.ncep.noaa.gov+ENSO+Alert+System+Watch+Advisory+definitions (October 23, 2026); search snippets were not used as evidence.
